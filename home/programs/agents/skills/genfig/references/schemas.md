# イメージスキーマ辞書

Johnson 1987『The Body in the Mind』が挙げる約27のイメージスキーマから、図に使える実用コアを
抜粋。各項目に **認識の手がかり**（自然文のどんな語がこのスキーマを示すか）と **レイアウト指針**
（`genfig.py` でどう描くか）を示す。1枚の図は複数スキーマの合成になることが多い。

| スキーマ | 認識の手がかり（語・状況） | レイアウト指針 |
|---|---|---|
| **SOURCE-PATH-GOAL** | 〜から〜へ、送る、移動、渡す、流れ、到達 | 起点→経路→着点を `connector` の片方向矢印で結ぶ。横並びが基本 |
| **LINK** | つながる、関連、接続、結びつく、依存 | 2ノードを線で結合（矢印なし or 細線）。関係名をラベルに |
| **CYCLE** | 往復、繰り返し、ループ、循環、戻る | 往路を `primary=True`、復路を `primary=False` で。または円環配置 |
| **CONTAINER** | 中/外、含む、入る、出る、属する、範囲 | `sticky` の枠を描き、内側に要素を配置。内外で意味を分ける |
| **VERTICALITY** | 上下、増減、階層、上位/下位、積み重なる | 縦に積む。上＝多い/上位、下＝少ない/下位。層間は `biconnector` |
| **CENTER-PERIPHERY** | 中心/周辺、コア、拡張、ハブ、本体と付属 | 中央に主ノード、周囲に放射状に副ノード |
| **PART-WHOLE** | 構成、〜からなる、部品、全体、まとまり | 全体を `sticky` 枠で囲み、内部に部品ノードを並べる |
| **FORCE: COMPULSION** | 押す、駆動する、強制、力で動かす | 太い矢印で力の向きを強調 |
| **FORCE: BLOCKAGE** | 阻む、遮る、ブロック、防ぐ、止める | 矢印の先に壁（縦長 `sticky`）を置き、矢印を壁で止める |
| **FORCE: COUNTERFORCE** | 対抗、ぶつかる、せめぎ合い、拮抗 | 左右から向き合う2本の矢印を衝突させる |
| **BALANCE** | 釣り合い、トレードオフ、対称、バランス | 中央軸に対し左右対称、または天秤状に配置 |
| **SCALE** | 大小、程度、段階、レベル、目盛り | 段階的に並べ、サイズや位置で大小を表す |
| **SPLITTING** | 分ける、分岐、振り分け、二手に | 1ノードから複数方向へ `connector` を分岐 |
| **MERGING** | 統合、合流、まとめる、集約 | 複数ノードから1ノードへ矢印を集約 |
| **NEAR-FAR** | 近い/遠い、距離、親密/疎遠 | 距離を座標で表現。近い＝接近配置 |
| **CONTACT** | 触れる、接する、隣接、境界を共有 | ノードを隣接・接触させて配置 |

## 合成の例

- 「リクエスト/レスポンス」= SOURCE-PATH-GOAL + CYCLE
- 「3層アーキテクチャ」= VERTICALITY + PART-WHOLE
- 「データを種類で振り分け」= SPLITTING + CONTAINER
- 「認証で弾く」= SOURCE-PATH-GOAL + FORCE:BLOCKAGE
- 「ハブ＆スポーク」= CENTER-PERIPHERY + LINK

## 写像のコツ

- 動詞に注目する。「送る/返す/渡す」は PATH、「含む/入る」は CONTAINER、「分ける」は SPLITTING。
- 往復・繰り返しの含意があれば CYCLE を重ねる。
- 抽象概念（処理・データ・状態など）も、身体的スキーマに落とすと図にできる
   （Lakoff & Johnson の「概念メタファーは身体的スキーマに基づく」の応用）。
