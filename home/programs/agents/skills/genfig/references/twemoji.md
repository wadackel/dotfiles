# twemoji 早見表

`genfig.py` の `emoji()` は twemoji（メンテ版 fork `jdecked/twemoji`）の SVG を CDN から取得し、
ローカルキャッシュ（`.twemoji-cache/`）した上で図にインラインする。コードポイント（hex）でも
絵文字文字列でも指定できる。

CDN: `https://cdn.jsdelivr.net/gh/jdecked/twemoji@latest/assets/svg/{codepoint}.svg`

## Cloudflare ハンズオン教材 標準割当（レクチャー間で統一）

cloudflare-introduction-handson の図はレクチャーをまたいで次の割当に統一する。
**関係（リクエスト/レスポンス/fetch/データ転送）は矢印のラベルで表し、絵文字ノードにしない。**

| 概念 | 絵文字 | codepoint |
|---|---|---|
| ブラウザ / クライアント / フロント(Pages) | 🌐 | `1f310` |
| サーバー（汎用マシン） | 🖥️ | `1f5a5` |
| Worker / API / 処理 | ⚙️ | `2699` |
| データベース / D1 | 🗄️ | `1f5c4` |
| R2 / ファイルオブジェクト | 📦 | `1f4e6` |
| 投稿 / 入力データ | 📝 | `1f4dd` |
| 構造化データ / 表 | 📊 | `1f4ca` |
| 画像 | 🖼️ | `1f5bc` |
| ローカル / 開発PC | 💻 | `1f4bb` |
| クラウド / 本番環境 | ☁️ | `2601` |
| マイグレーション / SQL定義 / 設定ファイル | 📜 | `1f4dc` |
| ブロック / 遮断（FORCE:BLOCKAGE） | 🚧 | `1f6a7` |
| 許可 / 成功 | ✅ | `2705` |
| ユーザー / 人（正規の利用者） | 👤 | `1f464` |
| 警告 / エラー / 攻撃者 / bot | ⚠️ | `26a0` |
| 鍵 / 認証情報 / APIキー | 🔑 | `1f511` |
| 錠 / セキュリティ / アクセス制御(Access) | 🔒 | `1f512` |
| 禁止 / 停止（アカウント停止・目的外利用） | ⛔ | `26d4` |
| フォルダ / 公開ディレクトリ | 📁 | `1f4c1` |

注意:
- 「フロント(Pages)」は 🌐（ブラウザと同じ＝Webの顔）。🖥️ はサーバー専用とし二重使いしない。
- **攻撃者 / bot は 🌐 ではなく ⚠️**。🌐 は正規のブラウザ/フロント専用。攻撃アクターは 👤 ではなく ⚠️ で表し、正規ユーザー(👤)と区別する。
- リクエスト・レスポンス・fetch は `connector` のラベルで表現する。

## 補足

- 異体字セレクタ `fe0f` はファイル名から落とすのが twemoji の慣習（`emoji()` が自動処理）。
- 合字（国旗・ZWJ 連結など）はハイフン区切りの codepoint 列。例 `1f1ef-1f1f5`。
- 一覧にない概念は、最も近い具体物を選ぶ（抽象語より身体的に掴める物の方が図に向く）。
- 不明なときは https://emojipedia.org で codepoint を確認できる。
