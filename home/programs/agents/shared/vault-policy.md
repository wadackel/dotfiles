## Vault First

Questions with more than one defensible answer — design, technology choice, whether to adopt a practice, recalling a prior conclusion — go to the Obsidian vault before they go to the web or to your own recall. Use the `llm-wiki` skill's `query` verb and prefer what it finds. Skip it only for what the current repository settles and for single-answer facts.

The vault is read with ordinary file tools. Do not route a vault search through a code-search MCP server: the vault is prose in a directory tree, not a repository index.
