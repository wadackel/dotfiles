# 和文に混ざる語の分類表

計測対象: `~/.claude/projects/` 全394ファイル、メイン対話 1,760応答、地の文
497,339字 括弧内は出現回数。10回以上の語のみ。

分類の原則 (現行の正本は `~/.claude/CLAUDE.md` の `### Writing` と
`writing-clarity/references/protected-terms.md`):

- 固有名詞は原語のまま残す。定義した側が名前として扱う語は訳さない
- 英語の専門用語は動作に書き下す
- カタカナ外来語は日本語で言い換える。定着した語は使ってよい
- 平易化は一般英語のみを対象とし、用語として機能する語は残す

## E. 効果の見積もり

- 英単語トークン総数: 22,200（44.55 / 1000字）
- うち10回以上の語でカバーされる割合: 72.7%
- B分類（訳すべき語）の合計: おおよそ 4,500〜5,000トークン

B分類をすべて置き換えると、英単語密度は 44.55 → およそ 34〜35 / 1000字
に下がる見込み。カタカナのC-2を併せて言い換えると、外来語トークン全体（58.67/1000字）は
40 前後まで下がる。

ただし A分類（固有名詞・プロジェクト語）が
1万トークン超を占めるため、**これ以上は下がらない下限**がある。この下限は正当なので、目標値は「ゼロ」ではなく「A分類のみが残る状態」に置くべき。
