横ばい〜上昇トレンドが**反転して低下**すること。判定は効果量が大きい場合のみ主張し、微差は不問。

## 再測定手順

```
~/.claude/scripts/writing-metrics/fire-rate.ts --from 2026-08-31
```

- 起点を 08-31 にするのは、改訂当日（08-30）には改訂前の応答が163件・58,475字蓄積済みで混入するため
- **判定には対象期間 200,000 字以上を要する**。未満なら判定保留として蓄積を待つ
- 実行は 2〜3 週間後を目安とする（repo CLAUDE.md の writing-metrics 定期運用に乗せる）

## 指標の注意

- **主指標は arrow_chain / paren_chain の2つ**。検出が辞書非依存で、protected-terms.md の許可語が今後増えても測定条件が変わらない
- telegraphic_fragment も辞書非依存だが副次観測（判定には使わない）
- mixed_latin_word / workflow_vocab は辞書依存の参考値。許可語の追記で下がり得るため、低下を規範遵守の改善と断定しない
- arrow_chain は絶対件数が薄く（約 7,700 字に1件）変動しやすい。pre 0.08 → post 0.13 の自然な上振れ履歴もあるため、小さな差を読まない

## 方向性確認（改訂当日の smoke、n=8）

矢印・括弧を誘発する日本語プロンプト8本を、改訂前後の concise.md それぞれで
`claude -p <prompt> --settings '{"outputStyle":"concise"}'` により実行し、出力を lint.ts で比較した。
検出できるのは「文面が完全に無視されている」失敗モードだけで、統計的主張はしない。
